# Cloud Computing & DevOps Internship - Task 1

Welcome to the Task 1 repository for the Cloud Computing and DevOps Internship. This project establishes the foundation for environment configuration, Git/GitHub setup, documentation standards, and basic shell automation.

##  Repository Overview

* **`configs/`**: Configuration templates and settings files.
* **`diagrams/`**: Workflow and architecture diagrams rendered via Mermaid.js.
* **`docs/`**: Technical guides covering installation, Linux commands, networking, and cloud concepts.
* **`notes/`**: Task logs and personal learning notes.
* **`screenshots/`**: Verification evidence for Linux version, Git config, SSH test, and repo structure.
* **`scripts/`**: Executable automation scripts.

##  Quick Start

Clone the repository and run the automated environment check script:

```bash
git clone git@github.com:NabeelaNisa/Cloud-DevOps-Intership.git
cd Cloud-DevOps-Intership
chmod +x scripts/system-check.sh
./scripts/system-check.sh
```
