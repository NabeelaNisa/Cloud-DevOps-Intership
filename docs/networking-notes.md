# Core Networking & Remote Access Fundamentals

Overview of essential networking principles utilized in cloud management.

## Key Concepts
* **IP Addressing:** IPv4/IPv6 allocation and subnetting.
* **DNS:** Resolution of domain names to IP addresses.
* **Ports:** Standard endpoints (HTTP: 80, HTTPS: 443, SSH: 22).

## SSH Protocol
Secure Shell (SSH) allows secure access to remote systems via keypair cryptography.
