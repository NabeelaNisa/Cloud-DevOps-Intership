# Troubleshooting & FAQ Guide

Common issues and fixes during Git configuration.

## 1. fatal: not a git repository
* **Fix:** Navigate into the repository folder using `cd ~/Cloud-DevOps-Internship`.

## 2. Permission denied (publickey)
* **Fix:** Verify key loading with `ssh-add -l` or re-add `~/.ssh/id_ed25519.pub` to GitHub.
